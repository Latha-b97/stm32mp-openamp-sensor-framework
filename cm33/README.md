# CM33 Projects

OpenAMP_TTY_echo

Purpose:
Minimal OpenAMP bring-up and validation project.This is an example project from the STM32Cube

Description:
This project demonstrates the most basic CM33 ↔ Linux communication using OpenAMP RPMsg TTY.
The CM33 firmware echoes data received from Linux back over /dev/ttyRPMSGx.

Key concepts:
OpenAMP initialization on CM33
RPMsg TTY channel creation
Basic message receive/transmit path
Linux-side testing using standard TTY tools

Role in the framework:
Foundation project used to verify:
OpenAMP is working
Remote processor boot is correct
RPMsg transport is functional


OpenAMP_TTY_Periodic_SeqQueue

Purpose:
Structured data transmission and reliability experiments.

Description:
Builds on OpenAMP_TTY_echo by introducing periodic data transmission and a sequence queue mechanism.
Instead of simple echoing, the CM33 sends structured messages at fixed intervals and tracks message ordering.

Key concepts covered:
Periodic CM33 tasks
Sequence numbers and basic reliability
Queue-based transmit model
Handling back-to-back RPMsg sends

Role in the framework:
Serves as a stepping stone toward sensor data streaming and flow-control aware designs.


OpenAMP_Sensor_Node

Purpose:
Primary CM33 firmware for sensor acquisition and Linux communication.

Description:
This is the main application project of the framework.
It integrates:

OpenAMP communication
Peripheral drivers (starting with I2C)
Sensor data acquisition (e.g., BME280)
Sensor data transport to Linux
Initially, sensor data is sent using RPMsg TTY, with future extensions planned for raw RPMsg endpoints.

Key concepts covered (progressively):
CM33 peripheral initialization (I2C, GPIO, etc.)
Sensor driver integration
Periodic sensor sampling
Sensor data delivery to Linux
Future flow control and control messaging

Role in the framework:
This project evolves through multiple versions (v2 → v5) and represents the production-oriented sensor node firmware.


TMP_CM33_I2C_OPENAMP

Purpose:
STM32CubeMX configuration reference project.

Description:
This project contains the STM32CubeMX .ioc file used to configure:

CM33 core
OpenAMP middleware
I2C peripheral
Clocking and system settings
It may include both CM33 and CA35 domains as generated by CubeMX, but it is not intended to be built or flashed.

Key concepts covered:
CubeMX-generated initialization code
Peripheral configuration source of truth
Regeneration reference for CM33 projects

Role in the framework:
Acts as a configuration anchor:
When peripheral or OpenAMP settings change, this project is updated
Relevant generated code is then manually ported into OpenAMP_Sensor_Node
