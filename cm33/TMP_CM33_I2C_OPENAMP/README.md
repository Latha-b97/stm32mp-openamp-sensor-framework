# TMP_CM33_I2C_OPENAMP

Reference STM32CubeMX project for STM32MP257F.

Purpose:
- Owns the `.ioc` file
- Defines CM33 + OpenAMP + I2C configuration
- Used to regenerate init code when needed

This project is NOT built or flashed.

Actual firmware lives in:
- OpenAMP_Sensor_Node


STM32CubeMX configuration reference project. This is a supporting project to generate the code for OpenAMP_Sensor_Node project.
Description:

This project contains the STM32CubeMX .ioc file used to configure:

    CM33 core
    OpenAMP middleware
    I2C peripheral
    Clocking and system settings

It may include both CM33 and CA35 domains as generated by CubeMX, but it is not intended to be built or flashed.
Key concepts covered:

CubeMX-generated initialization code Peripheral configuration source of truth Regeneration reference for CM33 projects
Role in the framework:

This is a temporary project mainly to generate the .ioc file and configure the I2C and OpenAMP. When peripheral or OpenAMP settings change, this project is updated Relevant generated code is then manually ported into OpenAMP_Sensor_Node
